# Public figures from already published summaries

This change populates the existing Figures and plots tab using numerical statements already present in the public test catalog. It does not read Tower, alter scientific results or issue Writer/independent-review receipts.

The existing Writer-approved visual import remains separate and unchanged. New presentation figures carry `presentation: PUBLISHED_SUMMARY`; they are labelled as visual summaries of published values, never new observations or new review approvals.

Every entry is bound by SHA-256 to all four bilingual public fields. Removal or any text revision drops the old derived figures. The renderer preserves source scope and limitations, separates units, uses points rather than fabricated curves, and exports the actual displayed numbers. Missing uncertainties are not estimated. Categorical indices are display positions, not physical measurements.

Software-validation figures remain tagged SOFTWARE_VALIDATION. Counts and simulation controls are not cosmological evidence. Dates identify figure publication, not test execution. All original public records, private routes, authentication and MCP are retained.

Coverage and excluded records are recorded in public-summary-figure-coverage.json. No private inputs or credentials are included.
