unicode-tables.mjs contains a generated transformation of public Unicode data,
obtained locally from CPython 3.12.14 and its Unicode Character Database 15.0.0.
Generation uses unicodedata.normalize('NFKD'), unicodedata.combining,
unicodedata.decimal, str.casefold, str.isalnum, str.isdecimal, and str.isspace.
No Python C source, private corpus, private query, or trained model is embedded.
The reviewed application stopword list is also included separately in the table.

The generator is export_unicode_tables.py. The table receipt records exact
runtime versions, source-function hashes, payload hash, module hash and sizes.
Changes: Unicode properties and mappings are transformed into JavaScript data;
identity mappings and algorithmic Hangul decomposition are omitted from the data
and handled by the original JavaScript implementation. This is not an official
Unicode or Python product, and neither organization endorses it.
