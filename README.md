# Dener Project Atlas 2.5D

Repositório visual e operacional dos projetos do Dener.

## App

- Atlas isométrico 2,5D
- 21 projetos iniciais
- dependências, artefatos, timeline e fontes canônicas
- busca, filtros, edição e persistência local
- importação e exportação do manifesto JSON

## Desenvolvimento

```bash
npm test
npm run check
npm run dev
```

O app é estático e pode ser publicado pelo Vercel usando esta branch como fonte.
